# Keyboard Tester

Interactive browser-based keyboard tester built with HTML, Tailwind CSS, and Web Audio API.

**Live Demo:** https://keyboard-tester-sma.vercel.app/

## Features
- Full keyboard layout with QWERTY and Dvorak switching
- Left/Right modifier and Numpad `event.code` inspection
- Synthesized mechanical switch audio profiles (Blue, Brown, Red)
- Dark and light theme support
